SHORT DESCRIPTION
------------------------------------------------------------
This pipeline summarizes evidence supporting the potential
functional relevance of selected non-reference sequence
(NRS) loci identified in the SABE cohort.

The workflow was applied to three candidate regions:

  - Chr21 locus
  - MED15 locus
  - TTC34 locus

For each locus, evidence from multiple analyses is
integrated to provide a concise overview of the genomic,
population, transcriptomic, proteomic, and disease-related
properties of NRS present in the region.

The resulting datasets provide:

- Genomic locations of candidate NRS
- Population frequencies in the SABE cohort
- Expression frequencies across RNA-seq datasets
- Cohort-specific expression patterns
- Disease association statistics
- Differential expression evidence
- Proteomic support through novel peptide detection
- FASTA and BED files for downstream analyses

PIPELINE OVERVIEW
------------------------------------------------------------

This workflow applies the same prioritization framework to
three candidate genomic loci.

For each locus:

(1) Identify NRS located within the target genomic region

(2) Retrieve genomic placement information from GENMAP

(3) Retrieve population frequency estimates from the SABE
    cohort

(4) Retrieve RNA expression evidence from public RNA-seq
    datasets and disease cohorts

(5) Evaluate disease enrichment using odds-ratio analyses

(6) Integrate differential expression results from lung
    disease cohorts

(7) Integrate proteomics evidence where available

(8) Generate summary tables, BED files, and FASTA files
    for downstream inspection

------------------------------------------------------------
EVIDENCE SOURCES
------------------------------------------------------------

GENMAP

  Provides genomic placement coordinates for each NRS.

------------------------------------------------------------

Population genetics

  Provides SABE population frequencies for each NRS.

------------------------------------------------------------

RNA-seq expression

  Expression frequencies are collected from:

    - Public RNA-seq datasets
    - ARMS cohorts
    - PRESTO cohort

------------------------------------------------------------

Disease association

  Odds ratios are calculated from disease and control
  patient counts derived from lung disease cohorts.

------------------------------------------------------------

Differential expression

  Differential expression evidence originates from the
  lung disease analysis workflow.

------------------------------------------------------------

Proteomics

  Novel peptide evidence is integrated where available.

  Detection of peptides overlapping an NRS provides
  additional support for potential biological relevance.

------------------------------------------------------------
NOTES
------------------------------------------------------------

- The three scripts implement the same general
  prioritization framework and differ primarily in the
  genomic locus being investigated.

- Input cohort-level and patient-level data are not
  included in this repository due to access restrictions.

- Several intermediate files originate from restricted
  institutional storage and cannot be redistributed.

- Absolute file paths present in the original scripts
  should be replaced by local paths before execution.

- This workflow is intended for prioritization and
  descriptive characterization of candidate NRS loci and
  does not perform formal statistical testing beyond the
  analyses generated in upstream pipelines.
