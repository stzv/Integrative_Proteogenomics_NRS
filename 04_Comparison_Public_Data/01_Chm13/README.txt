SHORT DESCRIPTION
------------------------------------------------------------
This pipeline compares SABE non-reference sequences (NRS)
against the complete telomere-to-telomere CHM13 human
reference genome.

The workflow aligns NRS contigs to CHM13, classifies
mapping status, extracts successfully mapped sequences,
and compares genomic placements between GRCh38-derived
locations and CHM13-derived locations.

The resulting datasets provide:

- CHM13 genomic placements of NRS
- Identification of NRS absent from GRCh38 but present
  in CHM13
- Comparison between CHM13 and GRCh38 locations
- Characterization of newly resolved genomic regions,
  including sequences placed in previously unresolved
  regions of the reference genome

------------------------------------------------------------
PIPELINE OVERVIEW
------------------------------------------------------------

(1) Align NRS against CHM13

    Script:
      00_minimap2.py

    Purpose:
      Align all NRS contigs against the CHM13 reference
      genome using Minimap2.

    Output:
      CHM13 alignment file (SAM format).


(2) Prepare auxiliary files

    Script:
      01_prep_files.py

    Purpose:
      Prepare NRS identifiers and supporting files
      required for downstream processing.

    Output:
      Processed NRS metadata tables.


(3) Classify alignment results

    Script:
      02_split_samfile.pl

    Purpose:
      Separate contigs according to mapping status and
      retain high-confidence CHM13 alignments.

    Output:
      Filtered alignment categories.


(4) Extract mapped NRS

    Script:
      03_Extract_Seqnames.py

    Purpose:
      Extract identifiers of NRS successfully mapped to
      CHM13 for downstream analyses.

    Output:
      NRS identifier lists.


(5) Compare GRCh38 and CHM13 placements

    Script:
      04_compare_CJ_Chm13Y_mappingv3.py

    Purpose:
      Compare genomic locations derived from CHM13 and
      GRCh38.

      Categorize NRS as:

      - Consistently mapped
      - Newly placed by CHM13
      - Mapped to alternative locations
      - Unresolved in GRCh38 but resolved by CHM13

    Output:
      Comparative placement tables and summary
      statistics.

------------------------------------------------------------
DECISION RULES
------------------------------------------------------------

CHM13 placements

  - Locations are based on high-confidence Minimap2
    alignments.

  - Alignment identity and completeness thresholds are
    inherited from the NRS partial-mapping workflow used
    throughout the project.

Comparison with GRCh38

  NRS are classified according to whether:

    - CHM13 confirms an existing GRCh38 placement
    - CHM13 provides a placement where none existed
      previously
    - CHM13 suggests a different genomic location
    - CHM13 resolves previously ambiguous mappings

NOTES
------------------------------------------------------------

- This pipeline evaluates the contribution of the CHM13
  reference assembly to NRS localization.

- The workflow was used to quantify NRS that could not
  be placed using GRCh38-based approaches but could be
  resolved using CHM13.

- Input data are not included in this repository.

- Several files originate from restricted institutional
  storage and cannot be redistributed publicly.

- Absolute file paths present in the original scripts
  should be replaced by local paths before execution.
