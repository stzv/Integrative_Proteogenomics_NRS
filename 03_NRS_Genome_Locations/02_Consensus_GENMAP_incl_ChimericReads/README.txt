SHORT DESCRIPTION
------------------------------------------------------------
This pipeline integrates genomic placement evidence
generated by multiple independent mapping approaches and
assigns a single consensus genomic location to each
non-reference sequence (NRS).

The workflow combines evidence from:

- 10X Linked Reads
- Anchoring
- Partial Mapping Coordinates (PMC)
- Chimeric RNA-Seq mappings

Locations supported by multiple methods are identified,
compared, and consolidated using predefined distance
thresholds and evidence-priority rules. The final output
consists of a single genomic placement assignment per NRS,
together with genomic annotations and overlap with known
gene models.

The resulting datasets provide:

- Integrated location evidence from all mapping methods
- Concordance between independent mapping strategies
- Final consensus genomic placements
- Gene annotation of mapped NRS
- Genomic context of NRS relative to known transcripts
  and genes

PIPELINE OVERVIEW
------------------------------------------------------------

(1) Merge mapping evidence into a unified location table

    Script:
      01_merge_locations_into_table.py

    Purpose:
      Combine mapping evidence from 10X, Anchoring, PMC,
      and Chimeric RNA-Seq into a single NRS-level table.

    Output:
      Integrated mapping-evidence table.


(2) Compare candidate locations between methods

    Script:
      01b_compare_locsv4.py

    Purpose:
      Identify concordant genomic placements predicted by
      different mapping methods.

      Pairwise comparisons are performed using distance
      thresholds specific to the precision of each mapping
      strategy.

    Output:
      Matched and unmatched location pairs.


(3) Assign consensus GENMAP locations

    Script:
      02_compare_CJ_mappingv4.py

    Purpose:
      Apply the GENMAP decision framework to select a
      single genomic placement for each NRS.

      Evidence from multiple methods is evaluated and
      prioritized according to predefined confidence and
      precision rules.

    Output:
      Final consensus genomic locations.


(4) Annotate consensus locations using gene models

    Script:
      03_GENMAP_vs_GTF.py

    Purpose:
      Compare finalized GENMAP locations to Ensembl /
      GENCODE gene annotations.

      Determine overlap with:

      - Genes
      - Exons
      - Introns
      - Intergenic regions

    Output:
      Annotated GENMAP location table.

------------------------------------------------------------
DECISION RULES
------------------------------------------------------------

Identification of matching pairs

  Two methods are considered concordant when they place
  the same NRS within the following distance thresholds:

  10X ↔ Anchoring      <= 50 kb
  10X ↔ PMC            <= 50 kb
  10X ↔ RNA-Seq        <= 50 kb
  Anchoring ↔ PMC      <= 1 kb
  Anchoring ↔ RNA-Seq  <= 50 kb
  PMC ↔ RNA-Seq        <= 50 kb

Single matching pair

  If exactly one matching pair exists, the final genomic
  location is assigned according to the following rules:

  10X + Anchoring
     -> Anchoring

  10X + RNA-Seq
     -> RNA-Seq

  Anchoring + PMC
     -> Anchoring

  PMC + RNA-Seq
     -> RNA-Seq

Multiple or no matching pairs

  If no unique matching pair can be identified:

  1. Use 10X location if available
  2. Else use a unique Anchoring location
  3. Else mark NRS as unmapped

Location standardization

  Anchoring:
    - ±500 bp window

  10X:
    - ±50 kb window

  RNA-Seq:
    - breakpoint-derived coordinates

  Mitochondrial, decoy, and viral locations:
    - retained unchanged

NOTES
------------------------------------------------------------

- This pipeline performs the final consensus location
  assignment for NRS.

- Placement evidence generated by 10X Linked Reads,
  Anchoring, and PMC is produced by the upstream pipeline:

      01_GENMAP_Based_10X_Anchor_PMC/

- Chimeric RNA-Seq evidence is incorporated during
  consensus assignment.

- The detailed GENMAP decision tree is described in the
  supplementary README "Genomic Placement of NRS (GENMAP Pipeline)"

- Input data are not included in this repository.

- Several files originate from restricted institutional
  storage and cannot be redistributed publicly.

- Absolute file paths present in the original scripts
  should be replaced by local paths before execution.
