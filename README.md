## Overview

This repository contains the analysis workflows used for the identification, characterization, genomic localization, transcriptional profiling, proteomic validation, disease association analysis, and functional prioritization of non-reference sequences (NRS) discovered in the SABE cohort.

## Repository Structure

### 01_NRS_Assembly

Assembly and characterization of non-reference sequences from discordant sequencing reads.

Main outputs:

- Final NRS assembly
- Partial Mapping Coordinates (PMC)
- NRS population frequencies
- Candidate chimeric NRS

---

### 02_Addition_HESMSV_to_UN

Comparison of NRS assemblies generated from:

- Unmapped reads only (UN)
- All discordant read categories (UN, HE, SM, SV)

Main outputs:

- Assembly comparison statistics
- Novel sequence content estimates
- Coverage analyses
- Contig length comparisons

---

### 03_NRS_Genome_Locations

Assignment of genomic locations to NRS using the GENMAP framework.

Integrated sources of evidence:

- 10X Linked Reads
- Anchoring
- Partial Mapping Coordinates (PMC)
- Chimeric RNA-seq mappings

Main outputs:

- GENMAP coordinates
- Consensus genomic placements
- Gene overlap annotations

---

### 04_Comparison_Public_Data

Comparison of NRS against external genomic resources.

Datasets include:

- CHM13v2+Y
- Public pangenome datasets
- NCBI non-redundant nucleotide database

Main outputs:

- CHM13-resolved NRS
- Publicly represented NRS
- Potentially novel SABE-specific NRS

---

### 05_NRS_RNA

Evaluation of transcriptional support for NRS using public RNA-seq datasets.

Main outputs:

- RNA-supported NRS
- Expression frequency tables
- Tissue-specific expression profiles
- RNA-seq saturation analyses

---

### 06_ORF_Prediction

Prediction and annotation of putative open reading frames (ORFs) encoded by NRS.

Main outputs:

- Predicted ORFs
- Functional annotations
- Candidate coding NRS

---

### 07_LC_MSMS_Analysis

Processing of LC-MS/MS datasets and identification of peptide evidence supporting predicted NRS-derived proteins.

Main outputs:

- Peptide-spectrum matches
- Supported ORFs
- Novel peptide candidates

---

### 08_Proteogenomics_Identification

Integration of transcriptomic and proteomic evidence for candidate NRS-derived proteins.

Main outputs:

- Proteogenomically supported NRS
- Novel peptide validation
- Prioritized protein-coding NRS

---

### 09_NRS_Lung_Diseases

Analysis of NRS expression in respiratory disease cohorts.

Datasets include:

- ARMS
- PRESTO
- THORAX

Main outputs:

- Disease-associated NRS
- Differential expression analyses
- Odds-ratio assessments
- Expression heatmaps and clusters

---

### 10_Potentially_Functional_NRS

Detailed characterization of selected candidate loci with evidence of potential biological relevance.

Case studies:

- Chr21 locus
- MED15 locus
- TTC34 locus

Integrated evidence includes:

- Genomic localization
- Population frequency
- RNA expression
- Differential expression
- Disease association
- Peptide evidence

## Workflow Overview

The analyses broadly follow the progression:

```text
NRS Assembly
      ↓
Genome Localization (GENMAP)
      ↓
Comparison with Public Resources
      ↓
RNA Expression Profiling
      ↓
ORF Prediction
      ↓
Proteomic Validation
      ↓
Disease Association Analysis
      ↓
Functional Characterization
```

Several downstream analyses reuse outputs generated by earlier pipelines. Individual pipeline README files describe required inputs, outputs, thresholds, and workflow logic in detail.
